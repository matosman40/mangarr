Patreon bloque les requêtes serveur et Mangarr ne contourne pas cette protection. Un petit script installé dans votre navigateur (déjà connecté à Patreon) envoie à Mangarr les exports JSON à télécharger et les derniers posts de vos créateurs. Tout est automatique ensuite : dès qu'un export arrive, le tome est téléchargé.

  1. Installez l'extension Tampermonkey (ou Violentmonkey) sur votre ordinateur.
  2. Installer le script Mangarr puis validez dans Tampermonkey.
  3. Ouvrez patreon.com : le script se lance seul (toutes les 3 h), ou cliquez sur la pastille « Mangarr ⟳ » en bas à droite.

Le script contient un jeton secret propre à votre Mangarr. S'il fuit, régénérez-le (il faudra réinstaller le script). Le navigateur doit pouvoir joindre {{ base }}.
